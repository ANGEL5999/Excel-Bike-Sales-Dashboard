
# 🚲 Bike Sales Customer & Purchasing Analytics Dashboard

An interactive Microsoft Excel dashboard built to analyze customer demographics, income levels, and commute patterns to evaluate purchasing trends for a bike retail business.

---

## 📊 Dashboard Preview
![Dashboard Screenshot](./git%20post%201.png)

---

## 💡 Key Business Insights

* **The Dispensable Income Threshold:** Buyers across both genders generally show higher average incomes compared to non-buyers ($56k+ for females, $60k+ for males).
* **The Commute Paradox:** Bike purchases drop off drastically once commute distances exceed 10 miles. The primary buying segment consists of customers commuting **0–1 miles**.
* **Core Demographic:** The **Adult** age category represents the largest volume of purchasers compared to Youth and Senior segments.

---

## 🛠️ Excel Skills & Features Applied

* **Data Cleaning:** Standardized values and text formatting using `TRIM()` and `PROPER()`.
* **Feature Engineering:** Built dynamic demographic age brackets using `IFS()` logic.
* **Aggregations:** Structured Pivot Tables for demographic segmentation.
* **Interactive UI:** Connected dynamic **Slicers** for real-time filtering across Region, Education, and Marital Status.
